# Contributing to TLS Cert Checker

Thank you for your interest in contributing to TLS Cert Checker! We're excited to have you on board. Here are some guidelines to help you get started:

## Reporting Issues
If you find a bug or have a feature request, please open an issue in this repository.

## Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or bugfix.
3. Make your changes and commit them, ensuring your code follows the project's style guidelines.
4. Push your branch and open a pull request.

## Code Style
- Follow the existing coding style in the project.
- Make sure to test your changes.

Thank you for contributing!
